# Snap (Snap Inc.)

> Snap Inc. is the technology company behind Snapchat, Bitmoji, Spectacles, and
> Lens Studio. Its Snap for Developers program exposes public APIs and SDKs for
> advertising (Snapchat Marketing API), identity (Snap Kit / Login Kit), and
> augmented reality (Camera Kit). Generated by the API Evangelist enrichment
> pipeline (method: generated, 2026-07-21) from the public developer docs.

## APIs

- [Snapchat Marketing API](https://developers.snap.com/api/marketing-api/Ads-API/introduction): OAuth 2.0 REST API at https://adsapi.snapchat.com/v1 for organizations, ad accounts, campaigns, ad squads, ads, creatives, media, audience segments, measurement, the Conversions API (server-to-server events), the Ads Gallery API, and the Public Profile API.
- [Snap Kit / Login Kit](https://developers.snap.com/snap-kit/login-kit/Technical-Documentation/OAuth2): OAuth 2.0 + OpenID Connect "Login with Snapchat", Creative Kit, and Bitmoji Kit.
- [Camera Kit](https://developers.snap.com/camera-kit/home): SDK and API for embedding Snap's AR Lenses into third-party mobile and web apps.

## Authentication

- OAuth 2.0 authorization code grant with refresh tokens.
- Authorize: https://accounts.snapchat.com/login/oauth2/authorize
- Token: https://accounts.snapchat.com/login/oauth2/access_token
- Bearer access tokens, 3600s TTL; refresh on 401 "token expired".
- Scopes: snapchat-marketing-api, snapchat-offline-conversions-api, snapchat-profile-api.

## Conventions

- Base URL: https://adsapi.snapchat.com/v1 (URI-path versioning).
- Cursor pagination via paging.next_link; limit 50-1000; ordered by CreatedAt.
- Response envelope: request_status, request_id, sub_request_status.
- Single-entity PATCH uses JSON Patch (application/json-patch+json).
- No client-supplied idempotency key.
